# v0.1.3

## 修复 / Fixes

- **字号可调，默认更小**：README 承诺的 DPI 缩放在 0.1.2 落地后字体在 150% 缩放下偏大（24px）。
  基准字号从 16 DIP 下调到 13 DIP（150% 下 19px），并新增 **菜单 → 显示 → 字号：小 / 标准 / 大 / 特大**
  （80/100/120/140%，对应 16/20/24/28px），改完立即生效并持久化到 `settings.json` 的 `text_pct`
  （手填 70–160 之间的任意整数也接受）。字体、圆点、间距、胶囊内边距、面板行高整套同步缩放。
- **不再把 console 子系统的 exe 打进商店包**：0.1.1.0 的 MSIX 载荷是 console 构建，双击会弹出一个
  覆盖桌面的终端窗口。`src/main.rs` 的 `#![windows_subsystem = "windows"]` 现在随源码入库，
  打包脚本会在产物不是 GUI 子系统时**直接中止**。
- **打包链路可复现**：`.cargo/config.toml`（`+crt-static`）入库——此前它在本地未跟踪，干净克隆构建出的
  exe 依赖 VC++ 运行库；新增 `tools/pack-msix.ps1` / `tools/pack-release.ps1` 统一出包并校验
  （GUI 子系统、静态 CRT、Setup 确实内嵌当前主程序），`msix/layout/*.exe` 不再入库。
- **应用运行中也能用调试子命令**：单实例检查移到子命令分发之后。此前 `probe` / `hidprobe` / `hidlisten`
  在应用运行时静默退出、0 字节输出。
- **罗技 HID++ 在 GUI 里真正生效**：此前只有 CLI 的 `enumerate(query=true)` 会查询 HID++，
  GUI 的监听器从不调用它，导致 README/商店描述里的"罗技支持"在界面上永远显示 `--`。
- **HID++ 帧长修正**：`OutputReportByteLength >= 20` 的集合（部分 Lightspeed）此前被写入 7 字节短帧，
  WriteFile 必然失败；现在按集合长度选择短/长帧。
- **EWEADN 校验和**：去掉 `report[last] == 0` 这条绕过分支——它让所有零填充帧跳过校验，并把我们自己
  发出的 `00 20 01 00 ...` 命令回显误读成「电量 0%」。
- **蓝牙枚举的硬超时**：`FindAllAsyncAqsFilter` 改走带 5 秒超时的封装，兑现模块文档与 README 的承诺
  （此前直接 `get()`，蓝牙栈卡死会永久阻塞轮询线程）。
- **生命周期与健壮性**：`WM_ENDSESSION` 时主动摘掉托盘图标；helper 窗口转发 `WM_DEVICECHANGE`
  （嵌入后条是 `WS_CHILD`，收不到顶层广播）；`SetParent` 失败只在错误码变化时写日志（真机上曾每秒刷屏）；
  降级浮动条改贴工作区边缘（原先压在 topmost 任务栏之下 = 看不见）；`+n` 热区每次重画清空；
  溢出面板高度不超过工作区；`max_strip_width` 下限防止 0 像素窗口。
- **设置与日志**：`known_devices` 满 40 后保留**最新**（此前 `truncate(40)` 会把刚加进来的设备当场丢掉，
  并每轮都触发写盘）；`settings.json` 改为原子写（临时文件 + rename）；`debug.log` 加 1 MiB 上限并轮转。

## 文档 / Docs

- README：内存改为**实测值**（工作集约 23–24 MB / 私有约 5 MB）、主题描述改为真实的固定高对比配色、
  轮询间隔补上 10 秒档与"无连接 15s"、DPI 与字号档说明、菜单表新增「字号」。
- PRIVACY：改为真实存储位置（`settings.json` + `debug.log` + `HKCU\...\Run`）。
- STORE-LISTING：删除 VC++ 运行库依赖声明（静态 CRT 后不再需要）。
- 新增 `docs/RELEASE.md` 发布清单与 `tools/publish-release.ps1` 一键发布脚本。

## 验证 / Verification

- `cargo test` 83 通过；`cargo build --release` 0 警告；`cargo fmt --check` 全绿；clippy 无新增告警。
- 真机（Windows 11 26100，2560×1440 @150%）：
  - 条嵌入 `Shell_TrayWnd`（`WS_CHILD`，父窗口正确，高度等于任务栏高度，与通知区间隙 6 DIP）；
  - 字号四档实测条宽比精确等于 80:100:120:140，默认字高 24px → 19px；
  - 退出 `exit=0`、无残留进程、无 TCP/UDP 连接、30 秒内存/句柄稳定（无泄漏）；
  - 商店包 A/B：旧 0.1.1.0 载荷双击弹出终端窗口，新 0.1.3.0 载荷零控制台窗口。
